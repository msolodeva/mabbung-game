# New roster artwork

Generated with the built-in image_gen tool. These are generated game assets, not extracted official sprites.

Final assets: `cammy-atlas.png`, `zangief-atlas.png`, `dhalsim-atlas.png`, `blanka-atlas.png` in this directory. Each contains 16 poses in a 4×4 grid (1792×1280).

The original generated RGBA atlases had valid transparency. `scripts/prepare-roster.py` isolates connected silhouettes and repacks them with padding to prevent neighboring poses leaking into a frame; it preserves source scale and alpha edges. The user authorized code-based background processing. Background-extraction variants were discarded.
