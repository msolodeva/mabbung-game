# Street Fighters — 2D Versus

TypeScript / Canvas로 만든 로컬 2D 격투 게임입니다. 이번 개선은 류·춘리와 주작성 도장을 중심으로 한 플레이 가능한 데모에 집중합니다.

## 실행

```sh
npm install
npm run dev
```

화면 아래에서 CPU 대전, 2인 대전, 트레이닝을 선택합니다. 캐릭터 선택은 1P WASD, 2P 방향키, 확정은 각각 F / Enter입니다. CPU·연습 모드에서는 방향키로 상대를 고른 다음 F로 시작합니다. 선택 화면에서 F3으로 스테이지, H로 CPU 난이도를 바꿉니다.

| 동작 | 1P | 2P |
| --- | --- | --- |
| 이동 / 점프 / 앉기 | WASD | 방향키 |
| 약공격 / 강공격 | F / G (J / K) | I / O |
| 필살기 / 초필살기 | H / R (L / U) | P / [ |
| 가드 | 뒤로 유지 또는 Space | 뒤로 유지 또는 Enter |
| 잡기 | F + G | I + O |

↓↘→ + 공격은 장풍, →↓↘ + 공격은 대공기, ↓↙← + 공격은 회전 공격입니다. ↑ + 필살기 / ↓ + 필살기로도 대공기 / 회전 공격을 사용할 수 있습니다. 초필살기는 게이지 한 칸을 사용합니다. 약공격이 맞거나 막힌 경우에만 허용된 후속 기술로 캔슬할 수 있습니다.

게임패드는 방향키·스틱 이동, A/X 약공격, B/Y 강공격, RB 필살기, RT 초필살기, LB 가드를 사용합니다. 두 패드는 각 플레이어에 대응합니다.

Esc 일시정지, F1 도움말, F2 판정 표시. 트레이닝에서는 F4 초기화, F6 더미 행동 변경, F7 정지, F8 한 프레임 진행을 지원합니다. 창에서 포커스가 벗어나면 자동으로 일시정지됩니다.

## 개선 내용

- 류·춘리 각각 32개 포즈의 투명 스프라이트, 대기·걷기·킥 동작과 피격·가드·다운·승리 표현
- 석양 도장 배경, 새 타이틀·캐릭터 선택·체력·게이지·초필살기 연출
- 렌더링 주사율과 분리된 고정 60Hz 시뮬레이션
- 기술별 발동·지속·회복 시간, 상하단 방어, 잡기와 동시 잡기 풀기, 카운터, 콤보 보정, 접촉 캔슬
- 양측 접촉을 먼저 수집해 동시타를 처리하는 판정, 장풍 상쇄와 중복 적중 방지
- 입력 버퍼, 짧은 키 입력 보존, 패드 버튼 최초 입력 감지
- 연습 더미, 입력 이력, 기술 단계와 프레임 진행, 판정 시각화

테리·이오리·가일·마이는 기존 절차적 렌더링을 유지하는 CLASSIC 캐릭터입니다. 신작 상용 격투게임 수준의 전체 애니메이션, 녹음 음성, 온라인 대전, 장기간의 밸런스 검증까지 완성한 버전은 아닙니다. 이미지 자산은 이 프로젝트를 위해 생성했으며 공식 게임에서 추출한 스프라이트가 아닙니다.

## 검증

```sh
npm test
npm run build
```

`tests/combat.test.ts`는 주사율 독립성, 동시타, 방어, 잡기, 무적, 장풍, 캔슬, 착지, 구석 충돌, 입력을 검증합니다. `tests/browser-smoke.js`는 개발 서버에서 Playwright CLI의 `run-code`로 실행하는 브라우저 시나리오입니다. 초필살기, 한 프레임 진행, 일시정지, 기본기, KO, 결과 화면, 작은 화면 레이아웃을 확인하고 `output/playwright/`에 스크린샷을 남깁니다. 테스트용 게임 상태 접근은 개발 모드에서만 제공됩니다.

주요 구현은 `src/combat/`(기술·접촉 판정), `src/entities/ArcadeFighter.ts`(전투 상태), `src/render/`(스프라이트·배경), `src/engine/Game.ts`(대전 흐름)에 있습니다.
